2018 年時我曾在 GitHub Pages 上放過幾篇前端框架筆記，後來忙於工作就停更了。現在重新用 Astro 架站，希望把**可重複查閱**的技術筆記與**實驗心得**整理在同一個地方。

## 我想記錄什麼

- 後端與 API 設計（C# / ASP.NET、Java）
- 前端與全端整合（Angular 等）
- AI 輔助開發的流程、工具與取捨
- 偶爾的學習雜記與除錯過程

## 給自己的提醒

1. **短文也沒關係**，重點是留下脈絡。
2. **程式碼範例要可讀**，將來的自己也會感謝現在的自己。
3. **中英文混用可以**，但標題與摘要盡量寫清楚。

若你也是很久沒更新個人網站的人，歡迎從一篇「為什麼開始」寫起——這篇就是這樣誕生的。
